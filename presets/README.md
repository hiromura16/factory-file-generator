### 01-quickstart

**小さく試す** · [JSONをダウンロード](01-quickstart.json)

- **想定する状況**　設備・検査装置・バッチ連携からランディングへ届くファイルを想定し、指定した形式の読み込み互換性を確認します。
- **このプリセットの内容**　同じ汎用項目を使用し、件数・速度・バッチを段階的に変更する負荷試験。大規模試験前に少量で接続先の性能と容量を確認します。 件数30、目標速度10件/秒（0は制限なし）。
- **確認すること**　パーサーの解釈、レコード数、文字コード、マニフェストのSHA256、画像とレコードの対応。
- **実行前の条件**　保存先の権限と容量を確認。job_idを含むパスなら実行ごとに別領域へ保存します。画像は人工パターンです。 設定は自由に変更して別名保存できます。
